# Example: tacit-knowledge-heavy writing

## Source document

조립2라인 프레스03 인수인계

7/23 10:15 기준 홀 직경 이슈 확인했습니다. 기준은 10.00±0.05mm이고, 확인한 12개 중 3개가 상한을 넘었습니다. 해당 시점 전후 제품 포함 186개는 격리해 두었습니다. 위치는 다들 아는 쪽으로 옮겨놨으니 품질과 확인할 때 그 기준으로 보면 됩니다.

금형 체결 토크는 재체결했고, 이후 시제품 5개는 9.98~10.03mm로 나왔습니다. 일단 현 조건으로 이어가되, 초반품은 평소보다 신경 써서 봐 주세요. 펀치 마모와 소재 두께는 아직 확인 전입니다. 교대 후 같은 느낌이 보이면 바로 멈추고, 애매하면 먼저 제가 보던 방식대로 판단 후 공유 바랍니다. 격리품 처리와 재가동 최종 판단은 품질 확인 뒤 진행하세요.

## Expected flags

- Require the isolation location, first-piece sampling method, and stop trigger to be explicit.
- Flag `다들 아는 쪽`, `평소보다`, `같은 느낌`, and `제가 보던 방식` as non-transferable tacit knowledge.
