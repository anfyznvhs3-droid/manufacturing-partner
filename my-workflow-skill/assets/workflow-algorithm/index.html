Manufacturing review algorithm

자료가 들어오면
사실로 바뀌는 과정

한 명의 운영자가 최대 20개 출처를 받아, 근거를 확인하고 모르는 것을 남긴 뒤 하나의 출력 계약으로 정리합니다.

한눈에 보는 쉬운 순서

자료를 받고, 잘게 나누고, 맞춰 보고, 사람에게 물어본 뒤, 한 장의 결과로 정리합니다.

1 · INPUT자료 받기문서와 기록을 모아요
→
2잘게 나누기문장을 작은 사실로 나눠요
→
3맞춰 보기자료가 같은지 비교해요
→
4사람에게 묻기모르는 것은 만든 사람에게 물어요
→
5 · 반복다시 확인하기틀린 곳을 고쳐 다시 살펴봐요
→
6 · OUTPUT한 장으로 정리확인 필요와 충돌을 함께 보여줘요

예 / 아니오로 따라가는 알고리즘

아니오가 나오면 억지로 통과하지 않고, 자료를 보충하거나 다시 확인합니다.

INPUT

자료가 들어옵니다

  • 엔지니어 자료문서·시험 기록·구두 인수인계
  • 출처 정보작성자·개정·구성·원본 위치
  • 벤더 자료데이터시트·기능 선언
→
ALGORITHM

다섯 번 확인합니다

1
등록출처 1~20개에 이름표를 붙인다
2
잘게 나누기문장을 작은 사실로 나눈다
3
맞춰 보기범위·구성·개정·시험을 비교한다
4
사람에게 묻기모호함과 누락을 원본 소유자에게 묻는다
5
마지막 확인틀린 곳을 고친 뒤 같은 형식으로 정리한다
→
OUTPUT

하나의 결과가 됩니다

  • 문서 상태ready / 확인 필요 / 충돌 / 자료 부족
  • 확인 큐누구에게 무엇을 물을지
  • 운영 권한보류 또는 거부
  • manufacturing-gate/v1모든 입력에 같은 형식
